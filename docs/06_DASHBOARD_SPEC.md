# Dashboard Spec

## Page 1: Overview

- Universe size
- Number of quarters
- Sector coverage
- Score distributions
- Missingness summary

## Page 2: Company Explorer

- Ticker search
- AI score trajectory
- Financial metric trajectory
- Peer comparison
- Evidence snippets, when available

## Page 3: Signal Analysis

- Signal vs future outcome scatter
- IC by quarter
- IC summary table
- Regression output table

## Page 4: Backtest

- Quintile return table
- Q5-Q1 long-short series
- Methodology and caveats

## Page 5: Report Generator

- Ticker-level AI maturity summary
- Financial context
- Peer rank
- Evidence-backed narrative
- Responsible-use disclaimer
